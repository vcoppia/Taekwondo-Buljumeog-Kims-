MIGRADOR·TKD

Asistente de migración de datos · v2.0

⚠️ IMPORTANTE — Lee antes de empezar:

Este asistente migrará tus datos desde la versión antigua (con PIN) a la nueva versión (con login).

Antes de continuar, debes:
✓ Haber creado tu cuenta en la app nueva
✓ Tener configurado Firebase Authentication
✓ Tener configuradas las reglas de seguridad de Firestore

Si aún no has hecho eso, primero lee la GUIA-FIREBASE.md.

1 Iniciar sesión con tu cuenta nueva

Ingresa con la cuenta que creaste en la app nueva. Los datos antiguos se moverán a esta cuenta.

2 Escanear datos antiguos

Buscaremos los datos antiguos de tu sede principal en Firebase.

3 Migrar datos a tu cuenta

Esto copiará todos los datos antiguos a tu nueva cuenta. Los datos antiguos NO se borrarán en este paso (puedes borrarlos manualmente después si quieres).

0%

4 Migración completa

Tus datos ya están en tu nueva cuenta.

✓ Listo, Víctor.

Ahora puedes:
1. Abrir tu app nueva (con el login)
2. Iniciar sesión con la misma cuenta
3. Verás todos tus alumnos, pagos, asistencias, exámenes, etc.

¿Borrar los datos antiguos?
Puedes hacerlo desde Firebase Console manualmente, o si quieres, te paso un script para eliminarlos automáticamente.
